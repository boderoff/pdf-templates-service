
# PDF Генератор

Программа для создания PDF из HTML шаблонов.  
Вставляешь переменные типа `{title}` — подставляются значения из JSON.

## Что внутри

- Python 3.14
- Flask (сервер)
- Quill.js (редактор)
- SQLite (хранение шаблонов)
- xhtml2pdf (генерация PDF)
- t-strings для подстановки

## Как запустить

```bash
python main.py
```

Открыть в браузере: `http://localhost:5000`

## Как пользоваться

### 1. Создать шаблон

- Слева редактор HTML
- Вставить переменные в фигурных скобках: `{title}`, `{author}`, `{date}`
- Можно кнопками вставить готовые переменные

### 2. Заполнить данные

Два режима:
- **Режим полей** — добавлять поля кнопкой "+ Добавить поле"
- **Режим JSON** — вводить JSON вручную

Данные синхронизируются между режимами.

### 3. Сохранить шаблон

- Ввести название
- Нажать "Сохранить"

### 4. Скачать PDF

- Выбрать шаблон из списка
- Заполнить данные
- Нажать "Скачать PDF"

### 5. Предпросмотр

- Нажать "Предпросмотр" — покажет HTML в правом окне

## API

| Метод | URL | Что делает |
|-------|-----|------------|
| GET | `/` | Страница с редактором |
| GET | `/templates` | Список шаблонов |
| POST | `/templates` | Создать шаблон |
| GET | `/templates/{id}` | Получить шаблон |
| PUT | `/templates/{id}` | Обновить |
| DELETE | `/templates/{id}` | Удалить |
| POST | `/render/{id}` | Сгенерировать PDF |
| POST | `/preview/{id}` | HTML предпросмотр |

## Шрифт

Для PDF с русскими буквами нужен шрифт `times.ttf` в папке `fonts/`
